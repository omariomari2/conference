# Conference website

An Express and EJS conference website with server-rendered pages and static assets.

## Run locally

```sh
npm ci
npm start
```

Open the address printed by the server.
The server entry point is `server.js`.

## Scope

Website implementation work. The repository does not establish ownership of the event, branding, or supplied content.
Retain the original attribution and confirm reuse permission before adapting client materials.
